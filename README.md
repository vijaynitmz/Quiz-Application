# 📝 Quiz Application

A simple **Java-based desktop Quiz Application** built with **Swing and AWT**. Users can enter their details, attempt multiple-choice questions, navigate between questions, and view their final score.

## ✨ Features

* 👤 Name & Roll Number input
* 📖 Quiz instructions
* ❓ Multiple-choice questions
* ⬅️ Previous / Next navigation
* 💾 Stores selected answers while navigating
* 🧮 Automatic score calculation
* 📊 Result display
* 🚪 Exit option

The application uses `ArrayList` to manage questions, options, correct answers, and user responses.

## 🛠️ Tech Stack

* **Java**
* **Java Swing** — GUI
* **AWT** — UI styling & event handling
* **ArrayList** — Data management

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone :https://github.com/vijaynitmz/Quiz-Application
cd Quiz-Application
```

### 2. Compile

```bash
javac Quiz.java
```

### 3. Run

```bash
java Quiz
```
